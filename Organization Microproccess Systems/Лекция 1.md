## Сравнительный анализ цифровых автоматов и МП систем
[[Микропроцессорная система|МПС]] уступают цифровым автоматам по параметру быстродействия.
На это есть 2 причины:
1. По объёму электрической схемы, или кол-во компонентов: классический ЦА проектируется исходя из принципов минимизации. В нём количество компонентов минимально, а значит минимизированна задержка
   ==Специализированный автомат МПС== избыточен, поскольку [[Микропроцессор|МП]] должен быть способен решать большее количество задач, следовательно цепи сигналов длинее, соответственно задержка больше.
2. Алгоритм функционирования ЦА (цифрового автомата) определяется его схемой с структурой при включении питания автомат "Знает" что ему надо делать.
   ==Алгоритм работы== [[Микропроцессор|МП]] задаётся программным обеспечением, при функционировании каждой команду процессор выбрасывает последовательно и тратит время на **выборку, распознование и выполнение**.
   С другой стороны МПС обладает рядом преимуществ:
   - Меньшее количество корпусов ИМС, следовательно более простые сборки и отладка;
   - Более высокая надёжность вследствие меньшего количества компонентов, контактов и связей (кристалл сложнее, компонентов меньше);
   - Меньше потребляемая мощность;
   - Лёгкость модификации и наращивание функций системы за счёт ПО (программного обеспечения).
Состоит из 2 основных компонентов:
Любая функционирующая [[Микропроцессорная система|МПС]] $\rightarrow$ ПО (программное обеспечение) и АО (аппаратоное обеспечение)
Программное обеспечение:
- Системное ПО **(СПО)** (драйвера и т. д.);
- Прикладное ПО **(ППО)**.
## Классификация МП
1. По количеству БИС (больших интегральных схем) [[Микропроцессор|МП]]:  однокристальные, многокристальные (адреса данных увеличены).
   32 - начали ломаться
   интерфейс и управление раздельно, начали терять в быстродействии
2. По назначению:
	1. Универсальные;
	2. Специализированные ([[Микроконтроллер|МК]]) (меньше универсальности, быстрее )
3. По виду обрабатываемого сигнала:
	1. Цифровые;
	2. Аналоговые.
![[OMPS#^group=UTTkNtA2]]
4. По организации структуры магистрали [[Микропроцессорная система|МПС]]:
	1. Многомагистральные (адрес и данные раздельно);
	2. Одномагистральные (адрес и данные обхъединены в одну).
5. По количеству одновременно выполняемых программ:
	1. Однозадачные;
	2. Многозадачные.
6. По организации памяти:
	1. С классической архитектурой *фон Неймана* $-$ используется единственное пространство памяти для размещения ####### и данных (в универсальных [[Микропроцессор|МП]]);
	2. С Гарвардской архитектурой используется раздельные адресные программы для размещения программ и данных.
	   Разные пространства, одни адреса ([[Микроконтроллер|МК]]).
7. По объёму системных команд:
	1. ***CISC*** процессор состоит из команд полного объёма;
	   Compleate Instraction System Command.
	2. ***RISC*** с системой команд сокращённого объёма;
	   Reduce Instraction System Command.
	   (быстрее универсальных, но со сложными задачами на CISC выполняется быстрее из-за большого количества команд
	   Пример:
	   CISC требуется 10 команд
	   RISC требуется 40 команд)
