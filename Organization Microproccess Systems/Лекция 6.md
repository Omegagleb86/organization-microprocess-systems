### Неклассифицируемые команды / команды различного соглашения
$IN\ PORT_{8};\quad(PORT_{8})\rightarrow(A)$
$OUT\ PORT_{8};\quad(A)\rightarrow(PORT_{8})$

$PUSH\ RR;\quad(RR)\rightarrow(\text{стэк});\ (SP)-2\rightarrow(SP)$
$PUSH\ PSW;\quad(PSW)\rightarrow(\text{стэк});\ (SP)-2\rightarrow(SP)$
$POP\ RR;\quad(\text{стэк})\rightarrow(RR);\ (SP)+2\rightarrow(SP)$
$POP\ PSW;\quad(\text{стэк})\rightarrow(PSW);\ (SP)+2\rightarrow(SP)$

>[!info] Чтобы получить значения из Ac
>Выполнить следующую цепочку команд:
>- $PUSH\ PSW$
>- $POP\ RR$
>- $MOV\ A,\ R$
>- $ANI\ \dots$

## Соотношение времени интервалов
![[Excalidraw/OMPS.md#^group=9qqwluha]]
Различается 10 типов машинных циклов:
1. Извлечение кода команды из памяти, ***==обозначается $M_1$==***;
2. Чтение данных из памяти;
3. Запись данных в память;
4. Извлечение из стэка;
5. Запись данных в стэк;
6. Ввод данных из порта;
7. Вывод данных в порт;
8. Цикл обслуживания прерывания;
9. Останов;
10. Обслуживание прерываний в режиме останов.

>[!info] Первый машинный цикл
>**Первым** машинным циклом при выполнении **любой** и **каждой** команды является $M_1$

Машинные циклы регламентируют определённый вид / режим взаимодействия [[Микропроцессор|МП]] со своим ближайшим окружением, для настройки окружения на предстоящий машинный цикл процессор в 1 такте формирует управляющее слово, которое они отправляют системному контроллеру.
Из этого слова, которое формирует управляющие сигналы.
