##### Команды группы исключающего или (сумма по модулю 2)
$XRA\ R\ :\ (A)\oplus(R)\rightarrow(A):(F)$
$XRA\ M\ :\ (A)\oplus((HL))\rightarrow(A):(F)$
$XRI\ data_{8}\ :\ (A)\oplus data_{8}\rightarrow(A):(F)$
Команды данной группы используется для выборочной инверсии определённых разрядов

|          | $x$ | $x$ |      $x$       | $x$ |     | $x$ | $x$ | $x$ | $x$ |
| -------: | :-: | :-: | :------------: | :-: | --- | :-: | :-: | :-: | :-: |
| $\oplus$ |     |     |                |     |     |     |     |     |     |
|          | $0$ | $0$ |      $1$       | $0$ |     | $0$ | $0$ | $0$ | $0$ |
|      $=$ |     |     |                |     |     |     |     |     |     |
|          | $x$ | $x$ | $\overline{x}$ | $x$ |     | $x$ | $x$ | $x$ | $x$ |
##### Команды инверсии (НЕ)
$CMA\ R\ :\ (A)\rightarrow(\overline{A})\not\rightarrow(F)$
$CMC\ R\ :\ (Cy)\rightarrow(\overline{Cy})\rightarrow(F)$

##### Команды преобразования содержимого ресурсов
Относятся к командам унарных операций. Применяется к содержимому таких ресурсов как: регистры, регистровые пары, ячейки памяти.
Команды выполняется над 8-разрядными операндами, оказывает влияние на флаги.
Команды выполняется над 16-разрядными операндами, ***НЕ*** оказывает влияние на флаги.

##### Команды инкримента
8-разрядные данные:
$\begin{matrix} INR\ R\ :\ (R)+1\rightarrow(R) \\ INR\ M\ :\ ((HL))+1\rightarrow((HL)) \end{matrix}\Bigg\}\rightarrow(F)$
16 разрядные данные:
$\begin{matrix} INX\ RR\ :\ (RR)+1\rightarrow(RR) \\ INX\ SP\ :\ (SP)+1\rightarrow(SP) \end{matrix}\Bigg\}\not\rightarrow(F)$
##### Команды декремента
8-разрядные данные:
$\begin{matrix} DCR\ R\ :\ (R)-1\rightarrow(R) \\ DCR\ M\ :\ ((HL))-1\rightarrow((HL)) \end{matrix}\Bigg\}\rightarrow(F)$
16 разрядные данные:
$\begin{matrix} DCX\ RR\ :\ (RR)-1\rightarrow(RR) \\ DCX\ SP\ :\ (SP)-1\rightarrow(SP) \end{matrix}\Bigg\}\not\rightarrow(F)$

#### Команды ветвления
Команды ветвления используется для изменения маршрутизации в программе
1. Команды безусловного ветвления выполняются без проверки каких-либо условий
2. Команды условного ветвления
   Ветвления происходят только при выполнении условий: в качестве условий проверяется состояния флагов. Причём для каждого флага существует 2 вида ветвления.
	1. Флаг активен
	2. Флаг не активен

### Вызов системных подпрограм через систему векторов
$RST\ i,\ i=\{0,\ 1,\ \dots,\ 7\}$
![[Excalidraw/OMPS.md#^group=VLoGkSCW]]
Команда $RESTART$ обращается к таблице векторов, эта таблица распологается, начиная с $0000$ адреса, состоит из 8 разделов из 8 байт в каждом.
Каждому $RESTART$ соответствует свой раздел.
Внутри раздела можно расположить:
1. Тело подпрограммы, если её размер не превышает 8 байт.
2. Команду ветвления для перехода на подпрограмму, если её размер превышает 8 байт.
